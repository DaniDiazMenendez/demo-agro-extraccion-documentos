# AGRO-03 | Extraccion de documentos agro

Demo estatica e interactiva para GitHub Pages sobre extraccion de remitos y contratos agropecuarios con Azure AI Document Intelligence.

## Caso de uso

**Industria:** Agro y Agroindustria  
**Escenario:** Documentacion y comercio  
**Demo:** Extraccion de documentos (remitos, contratos)  
**Solucion Microsoft:** Azure AI Document Intelligence  
**Valor:** Automatizacion de captura y menos errores

## Que muestra

1. Remito de entrega y contrato de compra de ejemplo.
2. Campos clave extraidos: fecha, documento, proveedor, destino, productos, cantidades, montos y condiciones.
3. Confianza por campo para revision humana.
4. Tabla estructurada lista para Excel, ERP, Fabric o Power BI.
5. Guion de demo en español.
