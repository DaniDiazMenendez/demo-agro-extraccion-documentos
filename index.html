Guion de demo

  1. Mostrar el problema: remitos y contratos se cargan manualmente.
  2. Seleccionar remito o contrato de ejemplo.
  3. Procesar el documento con Azure AI Document Intelligence.
  4. Mostrar campos detectados y nivel de confianza.
  5. Mostrar tabla final lista para Excel, ERP, Fabric o Power BI.
  6. Cerrar con el mensaje: menos errores y mayor trazabilidad.

Campos clave a extraer

  • Tipo de documento, número, fecha y proveedor.
  • Cliente / establecimiento / destino.
  • Producto, cantidad, unidad, precio y monto.
  • Condiciones comerciales, vencimiento y observaciones.
  • Confianza de extracción para revisión humana.
